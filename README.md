# Mixed Signals: Weight-Space Programming for EEG and ECG

Live page: https://daravaram.github.io/BioWSP/

Pre-print: https://arxiv.org/abs/2611.13758

Companion page to the pre-print (arXiv:2611.13758). Can a language model train a biosignal network by reasoning about physiology, instead of by gradient descent? Five experiments on EEG and ECG networks (reading, improving, repairing, debugging, and writing a network from zero) with Claude Opus 5.5, GLM-5.3 and DeepSeek-V4.1-Flash, plus the exact prompts and Opus's reasoning, step by step.

Dara Varam, Taraneh Aminosharieh Najafi and David Atienza, Embedded Systems Laboratory (ESL), EPFL.

`index.html` is built from the project's write-up sources. `figures/` holds the paper's figures as animated SVGs. `media/` holds the narrated overview video, its poster and its captions. ECG traces come from PTB-XL (Wagner et al., *Scientific Data* 2020, PhysioNet, CC BY 4.0). The head model in Figure 1 is the Lee Perry-Smith scan (Infinite-Realities), CC BY 3.0.
